# Вакансия DevOps-инженера в Сибинтек-Софт
ТЗ состояло из трёх заданий:
1. Теоретические вопросы(.txt файл также содержит и оба скрипта с ТЗ на них);
2. Написание скрипта для автоматического развёртывания докер-контейнера с dashy(script.sh);
3. Доработка скрипта из второго задания для запуска с готовой конфигурацией(script_conf.sh).
